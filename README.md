#  Student Records Management System (MERN)

A full-stack web application built with the **MERN stack (MongoDB, Express.js, React, Node.js) to manage student records.  
This project demonstrates CRUD operations, user authentication and password reset functionality using Nodemailer.

---

#  Features
- User Authentication
  - Signup with email and password
  - Login with credentials
  - Password reset via email (Nodemailer)
- *CRUD Operations
  - Add new student records
  - View student details
  - Update student information
  - Delete student records
- Email Integration
  - Password  sent directly gmail
- Responsive UI with React

Tech Stack
- Frontend: React, Tailwind CSS , Axios
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- Email Service: Nodemailer
